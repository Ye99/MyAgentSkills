# MyAgentSkills
A collection of specialized skills to extend the capabilities of AI coding agents.

## Available Skills

- **add-google-models-to-opencode** ([`add-google-models-to-opencode/SKILL.md`](add-google-models-to-opencode/SKILL.md)): Add or update Google provider models in the opencode.json configuration.
- **azure-cool-to-cold** ([`azure-cool-to-cold/SKILL.md`](azure-cool-to-cold/SKILL.md)): Safely preflight, convert, and verify one Azure Blob container from Cool to Cold with strict scope and approval guards.
- **book-notes-restructure** ([`book-notes-restructure/SKILL.md`](book-notes-restructure/SKILL.md)): Restructure reading notes in place to follow the source's real chapter hierarchy, regrouping scattered blocks verbatim, marking the reader's interleaved look-ups, and proving no data loss.
- **chatgpt-math-to-obsidian** ([`chatgpt-math-to-obsidian/SKILL.md`](chatgpt-math-to-obsidian/SKILL.md)): Convert ChatGPT-pasted LaTeX in Markdown notes (bare `[ ... ]` and `(\text{...})` delimiters) into Obsidian MathJax `$$...$$` and `$...$`.
- **cuda-major-upgrade** ([`cuda-major-upgrade/SKILL.md`](cuda-major-upgrade/SKILL.md)): Upgrade a Linux host across a CUDA major version, swapping the NVIDIA driver branch, keeping Docker GPU support, cleaning orphans, and verifying with real kernels on host and in containers.
- **deskew-crop-scanned-document** ([`deskew-crop-scanned-document/SKILL.md`](deskew-crop-scanned-document/SKILL.md)): Straighten a tilted scan (passport, ID, receipt) by levelling its printed text lines, crop to the document edges, and save one JPG at the original DPI and quality without growing the file.
- **dedup-copy** ([`dedup-copy/SKILL.md`](dedup-copy/SKILL.md)): Copy files from a source to a destination while eliminating content-identical duplicates via jdupes, with scored keeper selection, JSON logging, and independent verification.
- **download-youtube** ([`download-youtube/SKILL.md`](download-youtube/SKILL.md)): Download a YouTube video or its original-language captions with yt-dlp, choosing the original audio track and saving the file under the user's Downloads directory.
- **extract-data-from-windows-drive** ([`extract-data-from-windows-drive/SKILL.md`](extract-data-from-windows-drive/SKILL.md)): Copy only user data off an old Windows system drive with rsync. Excludes OS, programs, executables and caches; keeps AppData mailboxes and chat history; skips junctions and empty folders. Proves no data loss with a checksum pass and an independent inventory that lists every skipped file.
- **create_mcp_ext_apps** ([`create_mcp_ext_apps/SKILL.md`](create_mcp_ext_apps/SKILL.md)): Build MCP ext-apps using a reference architecture with reusable transport, registration, and UI runtime patterns.
- **extract-embedded-images** ([`extract-embedded-images/SKILL.md`](extract-embedded-images/SKILL.md)): Move embedded base64 markdown images into a sibling assets folder and rewrite references as Obsidian wiki-link image embeds.
- **externalize-image-and-extract-text** ([`externalize-image-and-extract-text/SKILL.md`](externalize-image-and-extract-text/SKILL.md)): Keep or move note images into assets while adding faithful OCR or visual transcription text near the image embed.
- **format-markdownfile-code-block** ([`format-markdownfile-code-block/SKILL.md`](format-markdownfile-code-block/SKILL.md)): Normalize Markdown notes so command/code lines are easy to read.
- **compare-gopro-backup** ([`compare-gopro-backup/SKILL.md`](compare-gopro-backup/SKILL.md)): Check a GoPro card against its backup by content hash, reusing `find-missing-files` and ignoring card database files the camera rewrites.
- **find-missing-files** ([`find-missing-files/SKILL.md`](find-missing-files/SKILL.md)): Find files present in a source directory that are missing from a destination directory, compared by content hash rather than filename.
- **fill-pdf-form-flattened** ([`fill-pdf-form-flattened/SKILL.md`](fill-pdf-form-flattened/SKILL.md)): Fill PDF forms by drawing values into the page content, not appearance-less annotations, so they never show blank in browser PDF viewers, and verify the result before sending.
- **fill-luggage-tag** ([`fill-luggage-tag/SKILL.md`](fill-luggage-tag/SKILL.md)): Fill printable luggage tag PDFs by asking for visible blank values, overlaying typed text, and preserving print scale.
- **AI-folder-poi-itinerary-rename** ([`AI-folder-poi-itinerary-rename/SKILL.md`](AI-folder-poi-itinerary-rename/SKILL.md)): Rename day-based media folders with AI-selected itinerary landmarks from EXIF GPS clusters, preserving chronological order with resumable state and failure diagnostics.
- **backup-jetson-orin-nano-docker** ([`backup-jetson-orin-nano-docker/SKILL.md`](backup-jetson-orin-nano-docker/SKILL.md)): Back up (and restore) a Jetson Orin Nano/NX boot NVMe plus QSPI firmware consistently from Force Recovery Mode with NVIDIA's `l4t_backup_restore.sh` in Docker, entering recovery without a jumper, with checksum verification of every file.
- **flash-jetson-orin-nano-docker** ([`flash-jetson-orin-nano-docker/SKILL.md`](flash-jetson-orin-nano-docker/SKILL.md)): Flash JetPack (QSPI firmware plus NVMe SSD) onto a Jetson Orin Nano/NX devkit in Force Recovery Mode by running NVIDIA's flash tools in an Ubuntu 24.04 container, with host NFS setup/teardown that restores the host's prior state.
- **jetson-ollama-upgrade** ([`jetson-ollama-upgrade/SKILL.md`](jetson-ollama-upgrade/SKILL.md)): Upgrade Ollama on Jetson using jetson-containers, build CUDA-enabled image, and verify newer model pull support.
- **link-opencode-skill** ([`link-opencode-skill/SKILL.md`](link-opencode-skill/SKILL.md)): Install local directories as OpenCode skills by creating symbolic links in `~/.config/opencode/skills/`.
- **locationiq-nearby-poi** ([`locationiq-nearby-poi/SKILL.md`](locationiq-nearby-poi/SKILL.md)): Implement and document LocationIQ Nearby POI lookups with safe API key setup and plan-aware rate limit handling.
- **markdown-obsidian-linker** ([`markdown-obsidian-linker/SKILL.md`](markdown-obsidian-linker/SKILL.md)): Enforce Obsidian-safe markdown headings so internal links like `[[#Header]]` resolve reliably.
- **markdown-topic-normalizer** ([`markdown-topic-normalizer/SKILL.md`](markdown-topic-normalizer/SKILL.md)): Normalize escaped topic markers into proper Markdown headings while preserving code fences and real lists.
- **opencode-clipboard-image** ([`opencode-clipboard-image/SKILL.md`](opencode-clipboard-image/SKILL.md)): Save clipboard images to timestamped files and return OpenCode-ready `@path` references.
- **photo-gps-from-exif** ([`photo-gps-from-exif/SKILL.md`](photo-gps-from-exif/SKILL.md)): Extract latitude/longitude from JPG, HEIC, and MOV files using exiftool with batch-friendly output.
- **find-local-food** ([`find-local-food/SKILL.md`](find-local-food/SKILL.md)): Find local restaurants and stalls along a trip route, verify current and historical awards, exact branches and dishes, and optionally save verified places in Google Maps.
- **google-maps-travel-times** ([`google-maps-travel-times/SKILL.md`](google-maps-travel-times/SKILL.md)): Estimate itinerary legs by car, transit, bike or walking for the actual trip weekday and departure time, with every stop pinned to its exact Google Maps place.
- **planning-travel-itineraries** ([`planning-travel-itineraries/SKILL.md`](planning-travel-itineraries/SKILL.md)): Research and optimize configurable, destination-aware travel itineraries with explicit travel time, geographic clustering, and privacy-safe reusable guidance.
- **review-tests** ([`review-tests/SKILL.md`](review-tests/SKILL.md)): Review test suites for redundant cases and maintainability while preserving fast, clear failure diagnosis.
- **rewrite-obsidian-image-notes** ([`rewrite-obsidian-image-notes/SKILL.md`](rewrite-obsidian-image-notes/SKILL.md)): Rewrite Obsidian notes that embed pasted text-heavy images into editable Markdown, stopping without changes when OCR or visual verification is unreliable.
- **setup-github-coauthors** ([`setup-github-coauthors/SKILL.md`](setup-github-coauthors/SKILL.md)): Set a repo-local git commit template with valid GitHub noreply co-author trailers for OpenCode, Claude, and Codex (using `openai` for `openai/codex`) with resolved account IDs and no hardcoded personal names or emails.
- **organize-photos-and-videos-by-day** ([`organize-photos-and-videos-by-day/SKILL.md`](organize-photos-and-videos-by-day/SKILL.md)): Organize large source trees into `%Y/%Y_%m_%d` using offline geo-timezone conversion, high-fidelity media copy, and no-loss verification.
- **upgrading-openclaw** ([`upgrading-openclaw/SKILL.md`](upgrading-openclaw/SKILL.md)): Upgrade an OpenClaw gateway from a terminal (never from its own chat), then run read-only post-upgrade checks for the customizations upgrades silently break: single OpenAI token refresher, agent-added provider blocks, ACP adapter Claude Code version, ACP permission mode, and systemd restart policy.
- **video-food-places-to-google-maps** ([`video-food-places-to-google-maps/SKILL.md`](video-food-places-to-google-maps/SKILL.md)): Verify video-mentioned food stalls on Google Maps, save open places with sourced dish and recommendation notes, and track them in a travel note.
- **upgrading-ubuntu-lts-release** ([`upgrading-ubuntu-lts-release/SKILL.md`](upgrading-ubuntu-lts-release/SKILL.md)): Upgrade an Ubuntu machine to the next LTS with `do-release-upgrade`, safely over SSH (headless servers, ZFS hosts, desktops): channel and pre-flight checks, detached root tmux, sudo-rs-safe watcher, evidence-based prompt answers, and pre-/post-reboot gates.
- **utm-backup-restore** ([`utm-backup-restore/SKILL.md`](utm-backup-restore/SKILL.md)): Back up and restore UTM VM bundles with full macOS bundle metadata.
- **verifying-zfs-replication** ([`verifying-zfs-replication/SKILL.md`](verifying-zfs-replication/SKILL.md)): Prove a ZFS replication between two hosts is exact: snapshot GUIDs, then metadata and SHA-256 of every path changed between two snapshots, read from the immutable `.zfs/snapshot` directories on both sides in parallel, with deleted paths checked absent.
- **virsh-delete-and-flatten-snapshots** ([`virsh-delete-and-flatten-snapshots/SKILL.md`](virsh-delete-and-flatten-snapshots/SKILL.md)): Remove libvirt external snapshot records or retire all restore points and reclaim QEMU/KVM overlay disk space with deterministic helper-script execution.
- **split-gopro-video** ([`split-gopro-video/SKILL.md`](split-gopro-video/SKILL.md)): Split GoPro HEVC MP4 files into named time-range segments with full fidelity — original bitrate, GPMF/GPS track, camera metadata, and accurate timestamps all preserved.
- **virsh-vm-apt-maintenance** ([`virsh-vm-apt-maintenance/SKILL.md`](virsh-vm-apt-maintenance/SKILL.md)): Patch one or more libvirt/QEMU/KVM Debian or Ubuntu guests unattended — start them in parallel, resolve each guest's IP from the DHCP leases, run `apt update`/`upgrade`/`autopurge` and `fstrim -av` over SSH, then restore each VM to the power state it started in.
- **virsh-vm-snapshots** ([`virsh-vm-snapshots/SKILL.md`](virsh-vm-snapshots/SKILL.md)): Manage external-only QEMU/KVM VM snapshots with `virsh` for UEFI-compatible backup workflows.
- **proxmox-cross-host-migration** ([`proxmox-cross-host-migration/SKILL.md`](proxmox-cross-host-migration/SKILL.md)): Move, copy, migrate, or restore QEMU VMs, CTs, and LXC containers between standalone Proxmox VE/PVE node hosts over SSH with `vzdump`/`qmrestore`/`pct restore`, preserving VMIDs, MAC addresses, and guest config while handling VMID collisions, the PVE 9.1.x unprivileged-LXC stdin-restore quirk, `--unique` MAC safety, linked clones, and templates.
- **obsidian-note-split** ([`obsidian-note-split/SKILL.md`](obsidian-note-split/SKILL.md)): Split an oversized Obsidian note into self-descriptive topic notes plus an index, regrouping scattered sections verbatim, rewriting heading links in and out, proving no data loss, and writing through the Obsidian CLI with post-write checks.
- **trip-bookings-from-email** ([`trip-bookings-from-email/SKILL.md`](trip-bookings-from-email/SKILL.md)): Reconcile a trip-planning note with booking emails, recording only reservations still active (booked-then-canceled ones are paired by confirmation number and skipped) and keeping PINs and management links out of the note.

## AI agent rules

- **[AGENTS.md](AGENTS.md)**: Best practice rules.
- Keep the global, always-loaded agent rule minimal and stable: core identity/persona, security guardrails, tool usage principles, system-wide constraints, and non-negotiable policies.
- Use skills for conditional, scoped capabilities: domain-specific instructions, task patterns (for example, "when writing PR reviews..."), rare workflows, specialized formatting rules, and tool-specific heuristics.
